# CYCNET White Corporate Redesign

Design direction:
- real corporate website look
- primarily white interface
- black/graphite typography
- restrained CYCNET blue
- no logo used as a page background
- no world map
- no dotted cyber background
- no oversized decorative tech graphics
- clean grids, thin borders, understated depth
- CYCNET content preserved

Replace photo placeholders using:
- assets/members/
- assets/events/
- assets/partners/

Run locally with VS Code + Live Server or by opening index.html.


## Partner logos
The Partners page now displays logo slots instead of partner names. Put the real logo images in `assets/partners/` using the filenames listed in `assets/partners/README.txt`.
